# 授权码

> dq-tool 项目文档,索引见根 [AGENTS.md](../../AGENTS.md)。本文覆盖离线授权码体系与授权码管理;安全侧约束另见 [代码约定与安全](代码约定与安全.md)。

- 离线 Ed25519 签名授权码(payload 为 客户名|有效期|软件版本|server_url|username|sid|签发时间戳|功能列表,`expires=permanent` 可签发永久授权,兼容两段/六段/七段旧格式),未激活/过期时除 `/api/license/**` 外所有接口 401,前端强制跳激活页
- 签发用 `scripts/LicenseKeygen.java`(**交互式**:依次提示输入私钥/客户/有效期/版本/扩展字段/功能列表,回车用默认值——客户默认「内部测试」、私钥默认 `license-private.key`、有效期默认 30 天后(可输入 `permanent` 永久)、版本默认取根目录 VERSION 文件去 `0.` 前缀、SID 回车自动生成 UUID;或 `make license` 快捷命令),公钥单独存文件 `server/src/main/resources/license-public.key`,`application.yml` 的 `dq.license.public-key-file` 只存文件路径(`classpath:` 前缀读 jar 内资源,否则按文件系统路径,兼容旧的内联 `dq.license.public-key`),私钥 `license-private.key` 不入库
- **授权码管理(仅管理员)**:yml 配 `dq.license.private-key-file` 指向签发私钥即为管理员实例,开放 `/license-admin` 页与 `/api/license/admin/codes` 接口(生成/留档 `license_record` 表/查看含完整码/删除,不可编辑;SID 未填时服务端自动生成 UUID 去横杠,页面不再提供输入框;删除仅删留档,离线方案无法吊销已分发码;非管理员访问 403 `LicenseAdminRequiredException`),管理端点在 /api/license 前缀下不被激活拦截(管理员实例可不激活使用)
- 软件版本号构建期由 gradle 去 `0.` 前缀注入 `app-version.txt`(与安装包版本一致),状态接口透出 `appVersion`/`admin`,首页底部页脚显示

## 功能列表(8 段新格式)

授权码 payload 第 8 段为**逗号分隔的功能 key 列表**,控制页面功能可用性(8 段新格式;2/6/7 段旧格式无该段,视为仅基础功能)。

功能定义见 `common/.../license/LicenseFeature.kt`(9 项):

| key | 功能 | 类别 |
|---|---|---|
| `scan` | 表级/字段级扫描检测、任务看板 | 基础(业务) |
| `datasource` | 数据源管理 | 基础(业务) |
| `excel` | 扫描结果 Excel 导出 | 基础(业务) |
| `report` | Word 数据调研报告导出 | 基础(业务) |
| `ai_doc` | AI 表说明 | 基础(业务) |
| `ai_tag` | AI 自动打标 | 基础(业务) |
| `tag` | 表标记与统计 | 基础(业务) |
| `logs` | 运行日志(SSE 实时日志页) | **受控**(系统) |
| `license_admin` | 授权码管理页 | **受控**(管理) |

规则:

- **基础功能集(`LicenseFeature.BASE_FEATURES`)= 全部业务功能,恒可用**,授权码中未列出也视为已授权 —— 已分发的旧格式授权码不受影响
- **受控功能(`logs`/`license_admin`)必须授权码显式包含**;未授权时前端隐藏入口、后端接口返回 403 `LicenseFeatureRequiredException`
- 最终授权集 = 基础功能集 ∪ 授权码显式包含的功能(`LicenseFeature.granted`),状态接口 `/api/license/status` 的 `features` 字段返回已授权 key 列表
- 签发对话框(授权码管理页)默认**全勾**,可取消;不传功能段(=仅基础功能)签发时传 `features: []` 或省略
- 旧格式授权码(2/6/7 段)解码后 `features=null`,按基础功能集处理(业务全放,受控功能不可用)

### 后端拦截

`WebServer.registerRoutes` 的 `beforeMatched("/api/*")` 在激活校验后追加受控功能校验:

- `/api/logs/**` → `licenseService.checkFeature(LicenseFeature.LOGS)`(需已激活 + 授权码含 `logs`)
- `/api/license/admin/**` → `licenseService.checkFeature(LicenseFeature.LICENSE_ADMIN, requireActive=false)`:管理员实例未激活直接放行(可不激活使用),已激活则要求授权码含 `license_admin`;过期仍拦截
- 业务功能恒有,不校验

### 前端入口控制

- 状态接口 `features` 供前端判断:侧边栏「运行日志」入口需包含 `logs`,`/license-admin` 路由与「授权码管理」入口需 `admin && features 含 license_admin`(`App.vue`/`LicenseFooter.vue`/`router` 守卫)
- 未授权功能前端隐藏入口 + 路由守卫拦截直接输入 URL;后端 403 兜底防绕过
