# 人工采集

> 把重点关注的表收藏起来,形成跨数据源的关注清单。类似「表标记」但语义更轻:不打分类、不参与统计,只是一份个人关注列表。

## 功能入口

- **侧边栏「人工采集」菜单**(路由 `/manual-collects`,页面 `ManualCollects.vue`,占 1 个固定页签):全部采集记录列表
- **表列表页(`Tables.vue`)**:工具栏「人工采集(N)」批量采集勾选表;操作列行内「采集/取消采集」切换单表

## 数据模型

- 迁移:`V28__manual_collect.sql`,表 `manual_collect`
- 四元组定位一张表:`datasource_id + db_name + schema_name + table_name`(唯一索引);`db_name` 空串兜底口径与 `table_tag` 一致(无库概念的方言存空串)
- `table_comment`:采集时的表注释快照(业务库注释可能随后变化,列表展示用)
- **无外键**:数据源被删后采集记录保留,列表数据源名显示兜底「数据源 {id}」(LEFT JOIN 空串)

## API(路由在 WebServer「人工采集」组)

| 方法/路径 | 说明 |
|---|---|
| `GET /api/manual-collects` | 全部采集记录(采集时间倒序),带数据源名;并按四元组补齐该表的标记列表(`tags`,含系统空表标记)与 AI 表说明(`description`) |
| `POST /api/manual-collects` | 批量采集 `{items:[{datasourceId, dbName, schemaName, tableName, tableComment}]}`,**幂等**:已存在(含请求内重复)跳过,返回 `{added, skipped}`;单表采集即一项的批量 |
| `DELETE /api/manual-collects/{id}` | 取消采集;记录不存在 400 |
| `POST /api/manual-collects/batch-delete` | 批量取消采集 `{ids:[...]}`,不存在的 id 跳过(幂等),返回 `{deleted}`;ids 为空 400 |
| `GET /api/datasources/{dsId}/schemas/{schema}/manual-collects?db=` | 某库下已采集 map:表名 → 记录 id(表列表页行内按钮状态) |

校验在内核 `ManualCollectService`:列表为空/schema/表名空/数据源不存在 → 400;批量内同一数据源只校验一次存在性。

## 列表页(ManualCollects.vue)

- 列:序号/数据源(链接跳库列表页)/库(链接跳表列表页)/表名(链接跳字段明细页)/注释/标记(该表 table_tag 标记,渲染同表列表页)/描述(AI 表说明 table_doc)/采集时间/操作(取消采集);**全部数据列可排序**(前端本地排序,标记列按标记名拼接比较)
- 过滤:关键字(表名/注释)、**数据源下拉**、**库下拉**(库选项随数据源筛选收敛);全部前端本地过滤
- 「导出」:当前过滤后的行按表格当前排序导成 Excel(复用通用列表导出 `POST /api/list-exports`,见 扫描与Excel导出.md);导出列与页面顺序一致(数据源/库/表名/注释/标记/描述/采集时间),不含序号/操作列
- 「库」列口径:多库数据源(SQL Server/Kingbase)显示 `db.schema`,其余只显示 schema,与页签标题口径一致
- 取消采集:二次确认后 `DELETE /manual-collects/{id}` 并就地移除行
- **批量取消**:勾选列多选后工具栏「批量取消(N)」可用,一次 `POST /manual-collects/batch-delete` 按 id 删除并就地移除行
- 表名链接:跳 `/datasources/:id/schemas/:schema/tables/:tableName`(带 `?db=&name=`,页签标题恢复数据源真名)

## 表列表页集成(Tables.vue)

- 工具栏「人工采集(N)」:勾选后可用,一次 `POST /manual-collects`,提示「新增 N 张,已存在跳过 M 张」
- 操作列「采集/取消采集」:按 `collectMap`(表名 → 记录 id)切换;加载时与表清单/标记等一并 `Promise.all` 拉取(失败静默为空 map)
- 标记筛选只读模式(`?tagId=`)下两个入口都隐藏,与其他操作类按钮一致
