# 导出中心

> 全部导出入口统一登记可查(V66 登记 / **V67 起 push 模型**,2026-09-18 实施;源方案 [导出中心实施计划](../plans/导出中心-实施计划.md))。
> 设计原则(用户定):**导出一个文件,导出中心就出现一条记录**,每条记录含**相对数据目录的详细路径、大小、描述、时间**。

## 方案:push + 点击即登记状态机(单表全量)

- `export_record` 表(V66 建表 + V67 `rel_path` + V68 `file_name` 可空),只记**元数据**。
- **点击导出立刻出一条「生成中」(RUNNING)记录——文件很大时导出中心马上可见**,随后各链路翻终态:
  - **同步流式导出**(扫描 Excel×2/扫描 Word/库结构 Word/预览/列表/4 种 JSON/导入模版/错误中心/比对导入原件):端点**入口** `recordStart`(params 记原路径)→ `downloadFile` 成功 `landed` 按文件名翻 SUCCESS + 回填 rel_path/size;前端失败 `POST /api/export-center/fail` 按路径标 FAILED;
  - **异步任务**(报告 Word/抽样 zip):提交即 `recordStart`(params 记 `key: 业务:<id>`,文件名可空待补)→ 完成 `finalize` 补 文件名/路径/大小;失败/取消删除/任务删除均标 FAILED;
  - **服务重启**:`recoverInterrupted()` 把残留 RUNNING 一律 FAILED(执行体已随 JVM 消亡)。
- V66 的「UNION 归一」随之废弃(单表即全量);只记成功,失败/进行中的任务不在此列(任务状态仍归原页面)。
- `list-exports` 一次性 token 取走即删、不可重放:记纯历史(params 空)。
- 诊断报告 .md(纯前端)与局域网 share 出口(实例间通道)不纳入。

## 统一模型

`ExportCenterItem`:id `KIND:自增id`、kind(ExportKind 枚举,15 值)、title(描述)、fileName(异步任务提交时可为空,终态补)、fileSize、storage(`NONE`=直存 exports/ / `DISK`=任务产物,仅作展示分色)、**relPath(相对数据目录的详细路径,打开/定位的唯一依据)**、checksum(文件 SHA-256 hex,V69 起;同步类 landed 实测、落盘类 finalize 计算/带入)、status(`RUNNING/SUCCESS/FAILED`)、error、createdAt/finishedAt。

- 列表 `GET /api/export-center?kind=&keyword=&start=&end=&page=&size=` → `{total, items}`;keyword 对 title/file_name LIKE,时间按创建日含当日。
- 回填 `POST /api/export-center/landed {fileName}`:统一直存成功后按文件名关联最新未回填登记,补 rel_path + 实测大小;无记录/文件缺失静默跳过。
- 删除 `DELETE /api/export-center/{kind}/{id}`:所有类型都是登记记录一律可删(仅删记录不动文件;页面未提供入口);未知 kind 400、不存在 id 400。
- 状态:`RUNNING(生成中)→ SUCCESS / FAILED`;列表存在 RUNNING 时 2s 轮询(页面已有口径),FAILED 行悬浮 error 看原因。

## 页面(web/src/views/ExportCenter.vue)

侧边栏「导出中心」一级菜单(授权**恒显**:`LicenseMenu.granted()` 对任何授权码并上 EXPORT_CENTER)。列:类型 tag / 描述 / 文件名 / **路径(relPath)** / 大小 / 状态 / 时间 / 操作。

- 文件名可点击 = 系统默认应用直开;操作列唯一入口「打开目录」= 文件管理器选中产物——**统一按 relPath 走 `POST /api/system/open` / `POST /api/system/reveal`**(后端把路径限在数据目录内)。「文件」列 = 文件名;**「校验和」独立列**(SHA-256 短显 16 位、悬浮全量;相对路径不再展示,2026-09-19 用户决策)。
- **完整性提示**:列表每行按 relPath 现算 SHA-256 与记录比对(带 size+mtime 缓存,轮询不反复哈希)透出 `fileState`——`TAMPERED`(源文件被改)**仍可点击打开,文件名旁打红色「已篡改」标签**(悬浮说明校验和不匹配);`MISSING`(磁盘上找不到/已删)= 删除线置灰禁点,「打开目录」降级为打开所在目录;`OK` 正常。无校验和的老记录只看存在性。
- 勾选 + **批量删除**(工具栏按钮,二次确认;逐条删登记记录,不动磁盘文件);筛选:类型下拉 / 关键字 / 创建时间范围。

## 埋点/推送清单

| 导出 | kind | 推送方式 |
|---|---|---|
| 扫描结果 Excel(任务/最新)/扫描 Word/库结构 Word/预览/4 种 JSON/导入模版 | SCAN_EXCEL 等 | 端点写流后埋点 + downloadFile 成功 landed 回填 |
| 列表 xlsx | LIST_XLSX | 同上(纯历史,params 空) |
| 错误中心导出(json/md) | ERROR_EXPORT | 端点埋点 + landed 回填(2026-09-19 补漏) |
| 比对导入模版 / 批次原件 | TEMPLATE / IMPORT_FILE | 端点埋点 + landed 回填(2026-09-19 补漏) |
| 比对 xlsx(V65 直盘) | COMPARE_XLSX | CompareController.export 直推(compare/) |
| 报告 Word | REPORT_DOCX | WordReportExportService.run 成功直推(reports/) |
| 抽样 zip | SAMPLE_ZIP | SampleExportService.runExport zip 完成直推(sample-exports/) |

文件名小工具 `ExportTrace.decode`(server/controller):文件名 URLEncoder 解码回展示名。
