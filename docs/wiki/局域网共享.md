# 局域网共享

> 同一局域网内多台电脑各跑一个 dq-tool 实例时,通过 UDP 广播自动互相发现,并可一键把对方实例的
> 标记、表描述、表所属系统乃至全部扫描记录拉取合并到本机,形成去中心化的客户端数据共享。
> 共享出口无鉴权,与整个工具一致**仅适合可信内网**。

## 能力总览

网络拓扑见 [../局域网共享拓扑.png](../局域网共享拓扑.png)(源文件 `../局域网共享拓扑.drawio`)。

- **自动发现**:每实例周期广播心跳(UDP,默认端口 17386),同网段其他实例出现在「局域网共享」页在线列表;
  超过 3 个心跳间隔(默认 15s)未再见到的实例自动判离线剔除。在线表纯内存,重启后重新发现。
- **手动添加实例**:UDP 广播跨不了子网/VLAN、AP 隔离等环境收不到广播时,在在线实例卡片右上角输入
  对方 `IP[:端口]`(端口缺省 10000)手动添加——服务端立即 HTTP 直连对方 `/api/lan/share/info`
  确认是本软件实例后才入库(连不上/对方版本无此端点报错),随后按心跳同间隔周期直连探测维护在线状态,
  离线判定与 UDP 心跳同一口径(3 倍间隔)。地址清单持久化在 `system_settings.lan_manual_peers`
  (V34,逗号分隔 host:port),在线表仍纯内存;手动实例带「手动」标签可单独移除;
  本机地址(回环/本机网卡 + 本机 HTTP 端口)在 HTTP 探测前就识别拦截,报「该地址是本机实例」,
  不会因 VPN/虚拟网卡地址探测超时误报「连不上」。
- **同步前预览与勾选**:两个操作入口都先拉取对方预览弹窗展示——**逐行明细**而非条数概览:
  标记清单(颜色/类型/描述)就地展示,表级打标(哪张表/哪个标记,未勾选标记的行标注「不同步」)、
  表描述原文经「明细」按钮弹窗查看(表所属系统不在弹窗展示,同步行为不变),扫描任务逐行
  (数据源/库/状态/表数/创建时间,标题带任务条数)。用户勾选后再同步:标记定义逐个勾选
  (未勾选标记的表级打标关系一并剔除),表级打标/表描述按类别勾选,扫描记录按任务勾选
  (`share/scans?ids=` 按 id 导出)。可多次增量补选。弹窗内各表格表头均固定。
- **数据源映射**:同一数据源在不同电脑上名称往往不同——弹窗里「数据源映射」以复选框逐行勾选
  (默认全选,取消勾选则该数据源下的打标/描述/扫描记录都不导入),并用下拉确认对应关系
  (同名自动预填),可选「现有本机数据源 / 新建到本机」。列表行按模式取口径:同步标记与描述=标注
  涉及的数据源;导入扫描记录=被勾选扫描任务涉及的数据源(随任务勾选动态增删)。
  新建副本同步
  名称/jdbcUrl/用户名/库过滤/分组,密码与 SSH 秘密字段以 TransferCrypto 密文随行
  (`GET /api/lan/share/datasources`,与数据源导出文件同一口径,无明文),落地即可连接。
- **同步标记与描述**:从选中实例拉取 标记定义 + 表级打标 + 表描述 + 表所属系统,按现有
  AnnotationTransfer 口径合并(标记按 name,表级数据按 数据源名+db+schema+table;数据源名匹配不到的行跳过)。
- **导入扫描记录**(原「导入全部数据」):标注段 + 勾选的扫描记录(含随任务携带的标注)。扫描记录导入的 mapping 为强制口径,
  此处自动按「对方数据源名 = 本机同名数据源 id」构建映射,匹配不到的数据源任务跳过并进 warnings;
  任务级去重(数据源+db+schema+创建时间)保证重复拉取不产生重复记录。
- **实例身份**:实例 id 首次启动时生成并持久化(system_settings.instance_id),实例名可改,
  空时回落主机名;改名在下个心跳即对 peer 生效。
- **本机信息展示**:「本机共享」卡片展示本机局域网 IPv4 地址清单(排除回环/链路本地,内网地址在前)+
  HTTP 端口的组合地址,点击即可复制——广播发现不到时把地址发给同事手动添加;
  数据来自 `GET /api/lan/status` 的 `httpPort`/`addresses`/`appVersion` 字段。
- **在线列表合并口径**:`peers()` = UDP 心跳发现 ∪ 手动实例直连探测,按 instanceId 去重(手动项优先,
  保留 manual 标记);preview/pull 均走该合并列表,手动实例与广播发现的实例操作完全一致。

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `dq.lan.enabled` | `true` | 总开关(配置文件默认);页面「局域网共享」的开关落 `system_settings.lan_enabled` 覆盖,即时启停 |
| `dq.lan.discovery-port` | `17386` | UDP 发现端口(心跳广播 + 监听),同一局域网各实例需一致 |
| `dq.lan.announce-interval-seconds` | `5` | 心跳间隔(秒),离线判定 = 3 倍间隔 |

桌面版数据目录 `config.properties` 同名键可覆盖(如 `dq.lan.enabled=false`)。

## 实现要点

- 内核(common):
  - `discovery/LanDiscoveryService.kt` — 纯 JDK DatagramSocket;心跳报文为小 JSON
    (`app=dq-tool-lan` + 协议版本 v + instanceId/名称/HTTP 端口/软件版本),按网卡广播地址逐目标独立发送
    (单个目标失败如网卡/VPN 断开的 Host is down 只记带目标地址的 warn、不中断其余目标,失败目标进
    10 分钟冷却暂停发送避免 warn 刷屏、到期重试一次,并随即重解析自动探测的目标列表),SO_REUSEADDR
    支持同机多实例(macOS 上叠加 SO_REUSEPORT——BSD 仅 REUSEADDR 时广播只投递给同端口绑定 socket
    之一,REUSEPORT 才全员投递);按 instanceId 过滤自身报文;
    peer 的 host 取报文来源 IP 而非自报。广播目标可注入 `InetSocketAddress` 列表(测试走回环单播)。
  - `service/LanShareService.kt` — 编排层:实例身份持久化、发现生命周期(开关即时应用,
    start 时记录 HTTP 端口供「关→开」就地重启)、共享出口(复用 AnnotationTransferService.export /
    ScanTransferService.export(全部任务))、主动拉取(HttpURLConnection GET 对端 share 端点,
    读入内存后 preview 自动构建数据源映射再 importJson;单类型失败记 errors 不中断)、
    手动实例(地址清单持久化,`lan-manual-probe` 守护线程按心跳间隔直连探测维护在线表,
    peers() 与 UDP 发现合并去重;parse/formatManualPeers 伴生函数便于单测)。
- 库表:V33 给 `system_settings` 单行表加 `lan_enabled` / `instance_id` / `instance_name` 三列
  (ALTER IF NOT EXISTS);V34 加 `lan_manual_peers`(手动实例清单);扫描/浏览器等其他列不受影响,
  resetScan 不清这些列。
- server 壳:`LanController` 挂 `/api/lan/**`:
  - `GET /api/lan/status`、`GET /api/lan/peers`、`PUT /api/lan/settings` — 本机页面用(走正常授权校验);
  - `POST /api/lan/peers/manual`、`DELETE /api/lan/peers/manual?host=&port=` — 手动添加/移除实例
    (添加时服务端先直连探测,失败 400);
  - `GET /api/lan/preview/{instanceId}` — 聚合对方 标注预览 + 扫描任务预览(同步前弹窗数据源);
  - `POST /api/lan/pull/{instanceId}` — 按勾选拉取,body `{annotations:{tagNames,includeTableTags,includeDocs,includeSystems}, scanJobIds}`;
    标注选择在本机侧过滤导出文件后再导入(`LanShareService.filterAnnotations`,内部函数便于单测);
  - `GET /api/lan/share/info` — 实例身份(实例 id/名称/版本),手动添加时直连探测用;
  - `GET /api/lan/share/annotations[/preview]`、`GET /api/lan/share/scans[/preview]`(scans 支持 `?ids=` 按任务导出)—
    实例间拉取出口,**授权前置校验放行**(peer 侧无本机授权上下文),就绪闸门仍生效(内核未就绪 503);
  发现服务在 `WebServer.finishInit` 内核就绪后启动(需要实际 HTTP 端口随心跳广播),失败只记 warn。
- 前端:`views/LanShare.vue`(本机共享设置卡 + 在线实例表,5s 轮询,切页签停轮询),
  路由 `/lan-share`,侧边栏「局域网共享」入口;启用开关切换即保存生效(失败回滚),实例名仍走「保存」按钮。

## 兼容与边界

- 心跳协议演进只追加字段,变更语义时升 `PACKET_VERSION`(旧版按版本不符忽略);数据文件格式
  完全复用 Transfer 体系,遵守「导入忽略未知字段 + 同版本追加可选字段」的向后兼容铁律。
- 网络限制:UDP 广播跨不了 VLAN/路由,部分办公网/AP 隔离环境收不到广播——此时自动发现的在线列表为空,
  用「手动添加」按 IP 直连(HTTP 探测,只需对方 HTTP 端口可达)即可照常同步;
  也可走原有手工导出/导入文件方式。共享出口无鉴权的边界不变。
- 大库扫描记录可能几十 MB,拉取走 HTTP 读超时 120s,前端该请求超时放宽到 180s。
