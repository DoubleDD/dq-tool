# 前端页面与按钮逻辑

> dq-tool 项目文档,索引见根 [AGENTS.md](../../AGENTS.md)。本文覆盖前端(web/)页面结构、页面间导航与各页面按钮/交互控件的触发逻辑,是改前端代码前先读的导航手册。

## 总体框架

- 技术栈:Vue 3 + Element Plus + vue-router + axios(`baseURL=/api`)。API 层统一走 `web/src/api/index.js` 的 axios 实例:401(非 license 接口)整页跳 `/activate` 并清 keep-alive;blob 错误体解析回 JSON 弹 message;统一 `ElMessage.error`。
- 布局(App.vue):`/activate` 为全屏独立页不渲染框架;其余页面 = 左侧 200px 侧边栏(一级功能导航,App.vue 内定义)+ 右侧(48px 头部[当前一级功能名 + 三档主题切换,自动/浅色/深色,存 `localStorage('dq-theme')`] + 页签栏 + 主内容(`keep-alive` 缓存 20 个,key=`route.fullPath`))。
- 侧边栏「数据源」为**可展开树**(el-sub-menu):子项「全部数据源」(→ 列表页)+ 各数据源(带 DbTypeIcon,点击直接进该数据源库列表);标题右侧 ⋮ 下拉提供「新增数据源 / 导入配置 / 导出配置(JSON)」。数据源列表由 App.vue 拉取 `/api/datasources`(进入数据源相关页、展开子菜单时刷新,失败静默维持旧列表)。
- 侧边栏「数据源」操作下拉通过 `tabState.pendingDsDialog`(stores/tabs.js)传递命令,数据源页消费后清空并打开对应对话框。**不用路由 query**——App.vue 的 keep-alive 以 `route.fullPath` 为 key,query 变化会导致组件重挂载、弹框状态丢失。
- 侧边栏高亮:`activeNav` 按路由前缀推导——`/datasources` 高亮「全部数据源」,`/datasources/:id/*` 高亮对应数据源项并自动展开树,`/scans*` 高亮「任务看板」(任务域),其余一级页各自命中;`/license-admin` 仅 `status.admin` 显示入口。
- 页签栏 `v-if="tabState.tabs.length"`:一级页面不占页签,全部下钻页签关闭后整条隐藏。

### 页签系统(`stores/tabs.js`)——理解页面关系的前提

> 一级功能页(数据源/任务看板/标记统计/报告列表)由侧边栏导航直接切换,**不占页签**;页签只管理工作流下钻页。

| 页签 | key | 行为 |
|---|---|---|
| 每数据源 1 个 | `ds-{id}` | 可关闭;库列表→表列表→扫描记录在**同一页签内下钻**,标题随路由动态变(由 `resolveTab` 推导) |
| 每扫描任务 1 个 | `scan-{jobId}` | 可关闭;**关闭时优先跳回其来源数据源页签**(`scanDsIds` 缓存),而非相邻页签 |
| (空态兜底) | — | 关闭最后一个页签后 `activeKey=''`,跳回 `/datasources`(侧边栏可重新下钻) |

### 路由守卫(`router/index.js`)

- 除 `/activate` 外每次导航先查 `GET /api/license/status`(Promise 缓存,并发共享);未激活/已过期 → `/activate`;激活成功后 `markActivated()` 更新缓存避免守卫重复查询。
- `/license-admin` 额外要求 `status.admin`,非管理员回 `/`。
- 各页包屑用 `Breadcrumb.vue`;「返回」按钮走 `utils/back.js`:有浏览历史 `router.back()`,无历史才兜底 push。

## 页面导航全景

```
/activate  激活页(授权失效时全局被赶到这里)
  ↓ 激活成功
侧边栏一级导航(不占页签,点击直接切换):
  /datasources  数据源·首页(卡片)
  /dashboard    任务看板
  /tags         标记统计
  /report-exports 报告列表
  /logs         运行日志(SSE 实时日志)
  /license-admin 授权码管理(仅管理员;页脚 LicenseFooter 也有入口)
  ↓ 点卡片/浏览库(数据源页签内下钻)
/datasources/:id/schemas  库列表 ─┬→ /datasources/:id/schemas/:schema/tables  表列表(数据源页签内下钻)
      (数据源页签内)            │      ├─ 已扫描 → ?jobId= 字段统计(同页签)
                                │      └─ 未扫描 → /datasources/.../tables/:tableName  字段元数据(页签内)
                                └→ /datasources/:id/schemas/:schema/scans  扫描记录
                                        └→ /scans/:jobId  扫描详情(新开扫描页签)
                                               └→ /scans/:jobId/tables/:name  字段统计(旧路由兼容)
/dashboard  任务看板 ─→ /scans/:jobId
/tags  标记统计 ─→ 表列表?tagId=&tagName=(只读筛选模式)
/report-exports  报告列表 ─-> 下载/打开/另存为
/logs           运行日志(SSE 实时)
```

## 逐页面按钮逻辑

### 首页/数据源管理 `Datasources.vue`(`/datasources`)

卡片网格展示全部数据源;未设密码的卡片红色警示 + 禁用浏览。**每次切回页签都刷新**(`onActivated`)。

| 按钮/控件 | 触发行为 |
|---|---|
| 导出 | 默认全选 → 弹导出框 → `window.open('/api/datasources/export?ids=...')` 直接下载 JSON |
| 导入 | 弹导入框(文件/粘贴两模式),支持 `.json` / Navicat `.ncx` / DataGrip 剪贴板;`FormData POST /datasources/import`,展示 总数/成功/自动改名/失败原因 |
| 新增/编辑 | DataGrip 风格对话框,**常规/SSH隧道/库过滤/高级 4 页签**;编辑态秘密字段(密码/私钥/口令)一律不回填、留空=不修改;保存 `POST /datasources` 或 `PUT /datasources/:id` |
| 测试连接 | `POST /datasources/test`,失败切回对应页签提示 |
| 删除 | 二次确认 → `DELETE /datasources/:id` → 刷新 |
| 库过滤「加载库列表」 | 编辑态连接未改走 `GET .../databases?all=true`(SQLServer 用 `/schemas?all=true`),否则 `POST /datasources/preview-databases` 按表单实时连接;保存 `PUT /datasources/:id/schema-filter`(全勾/全不勾=不过滤) |
| 数据库类型下拉 | 自动切默认端口(MySQL 3306 / PG 5432 / DM 5236 / KINGBASE 54321 / OB 2881 / SQLServer 1433 / Oracle 1521) |

### 库列表 `Schemas.vue`(`/datasources/:id/schemas`)

表格展示库 + 每库最近扫描状态/进度/标记;有运行中任务时每 2s 轮询统计(标记接口失败保留旧数据)。

| 按钮/控件 | 触发行为 |
|---|---|
| 批量扫描 | 勾选库 → 二次确认(内嵌「AI 自动打标」复选,模型可用默认勾 + 并发线程数,留空用配置默认)→ `POST /scans` 逐库提交(tables=null 整库);自动跳过正在扫描的库 |
| 更多->导出报告 | 勾选则导出勾选库,否则导出全部已完成全表扫描的库(需确认)-> `POST /datasources/:id/report/exports` -> 成功后询问是否跳「报告列表」页 |
| 更多→库过滤 | 弹过滤弹窗 → 保存 `PUT /datasources/:id/schema-filter` |
| 库名链接 | 下钻表列表页 |
| 描述-编辑 | 弹窗 → `PUT /schemas/:name/description`(供 Word 报告「实例描述」,留空即清除) |
| 标记块(前 3 个 + "+N") | 点击跳表列表并带 `?tagId=&tagName=` 只读筛选 |
| 扫描(行内) | 同批量扫描的确认+提交;正在扫描的库禁用 |
| 扫描记录(行内) | 跳扫描记录页(从未扫描过则禁用) |
| 数据库下拉 | 仅 SQL Server 多库场景显示,切换重载列表 |

### 表列表 `Tables.vue`(`/datasources/:id/schemas/:schema/tables`)

扫描主入口。支持本地筛选(搜索 / 标记多选 OR 逻辑 / 只看空表,`onlyEmpty` 按有效行数=0 过滤)。

| 按钮/控件 | 触发行为 |
|---|---|
| 开始扫描 | 弹扫描对话框:**强制全量 switch、表大小上限(数值+MB/GB,实时提示将跳过的表数)、AI 自动打标复选、并发线程数(数值,留空用配置默认,默认值经 `GET /scans/defaults` 拉取展示)、空值规则(列名+逗号分隔值)**;提交 `POST /scans`,范围优先级 单表 > 勾选 > 全库;成功跳 `/scans/:jobId?schema=库名` |
| 导出报告 | 单库 `POST /datasources/:id/report/exports`;未扫描时后端 409 拦截(blob 错误体解析出提示) |
| 生成描述(批量) | 勾选表并发 2 逐条 `POST /tables/:name/doc`(130s 超时),汇总成功/失败数 |
| 表名链接 | 已扫描 → `/scans/:jobId/tables/:name` 字段统计;未扫描 → 字段元数据页(旧版 jobId 数字兼容) |
| 描述列 | 无描述显「生成描述」/有描述显刷新图标(都调 `POST /tables/:name/doc`);点文本弹窗编辑 `PUT /tables/:name/doc`(2000 字上限) |
| 打标(行内) | 弹 `TableTagDialog`(见组件) |
| 扫描进度条 | 仅运行中表显示,点击跳扫描详情 |
| **只读筛选模式** | 带 `tagId` 进入时:顶部 alert + 「清除筛选」;隐藏 批量生成描述/开始扫描/打标,表名仍可点 |

### 扫描链路(Scans / ScanDetail / TableColumns / TableColumnsMeta)

| 页面 | 按钮/控件与行为 |
|---|---|
| 扫描记录 `Scans.vue` | 刷新;查看→详情;继续扫描 `POST /scans/:id/resume`(仅 CANCELED/INTERRUPTED/FAILED 显示);导出 Excel;删除(仅非 PENDING/RUNNING,二次确认);有运行中任务时每 2s 轮询 |
| 扫描详情 `ScanDetail.vue` | 取消 `POST /scans/:jobId/cancel`(仅 RUNNING,二次确认);继续扫描;导出 Excel;表名链接(仅 DONE)进字段统计;非终态(DONE/FAILED/CANCELED/INTERRUPTED 为终态)每 2s 轮询;回写 `setScanSchema/setScanDs` 供页签标题与关闭跳回父级数据源页签;描述区展示 并发线程数(未自定义显示「默认」) |
| 字段统计 `TableDetail.vue`(带 jobId) | 导出 Excel;关键字过滤;只看空字段 checkbox/链接;各列排序。空值数 = nullCount + emptyCount + ruleHitCount;另展示索引结构 |
| 字段元数据 `TableDetail.vue`(无 jobId) | 未扫描表的字段/索引结构预览(无统计列),仅搜索框,提示去表列表发起扫描 |
| `JobTimeline.vue` | 状态 tag 悬停 tooltip 展示任务事件链(创建/开始/继续/完成/失败/取消/中断);首次 RUNNING 显「开始」,后续 RUNNING 显「继续」(续扫) |

### 任务看板 `Dashboard.vue`(`/dashboard`,侧边栏入口,不占页签)

- 进行中任务卡片(点击→扫描详情页签;悬停显「取消」)→ `POST /scans/:id/cancel`
- 近期历史表格(20 条):查看 / 继续扫描 / 导出 Excel / 删除
- 有进行中任务时每 2s 轮询 + 1s 秒针驱动卡片耗时显示

### 标记统计 `TagStats.vue`(`/tags`,侧边栏入口,不占页签)

- 左侧标记列表:新建 `POST /api/tags` / 行内编辑 `PUT /api/tags/:id` / 删除 `DELETE /api/tags/:id`(二次确认,提示已打的 N 张表自动解除);系统「空表」EMPTY 标记不可编辑/删除
- 右侧:选中标记分布统计 `GET /api/tags/:id/stats`(总表数/行数/列数/标记覆盖表数;行/列为 null 显「—」)+ 分布表(数据源/库/表数/行数/列数,可排序,合计行)
- 分布表「表数」link → 表列表只读筛选模式

### 报告列表 `ReportExports.vue`(`/report-exports`,侧边栏入口,不占页签)

Word 报告异步任务列表;关键字 + 状态下拉(PENDING/RUNNING/DONE/FAILED)过滤;PENDING/RUNNING 每 2s 轮询(无活跃任务即停)。

| 按钮 | 触发行为 |
|---|---|
| 文件名 link | `POST /api/report-exports/:id/open` 系统默认应用打开(仅 DONE 且有文件名) |
| 另存为 | tauri 环境 `invoke save_report_as` 原生保存对话框(仅 DONE,非 tauri 不渲染) |
| 下载 | 浏览器直下 `GET /api/report-exports/:id/download`(`<a>` 点击,仅 DONE 非 tauri) |
| 打开目录 | `POST /api/report-exports/:id/reveal`(仅 DONE) |

### 运行日志 `Logs.vue`(`/logs`,侧边栏入口,不占页签)

程序实时日志查看页。通过 `EventSource` 订阅后端 SSE 端点 `GET /api/logs/stream`(后端 `LogStreamAppender` 挂载在 root logger,推送到所有订阅者;连接时先推送最近 500 条历史日志,再实时推送新日志,条目为 JSON:{timestamp/level/thread/logger/message/stackTrace})。

| 按钮/控件 | 触发行为 |
|---|---|
| 连接/断开 | 手动建立/关闭 SSE 连接;连接失败(如后端重启)由浏览器自动重连,收到消息即恢复「已连接」 |
| 级别下拉 | 按最低级别过滤(选 ERROR 只看 ERROR,选 WARN 看 WARN+ERROR,依此类推) |
| 搜索框 | 按 消息/logger/堆栈 本地关键字过滤 |
| 自动滚动到底部 | 默认开;关闭后新日志不再抢占滚动位置 |
| 清空 | 清空前端已收日志(不影响后端流) |
| 页签生命周期 | `onActivated` 自动连接、`onDeactivated` 断开,避免后台页面占用连接;前端最多保留 2000 条防内存膨胀 |

## 贯穿性交互机制

1. **轮询纪律**:扫描相关页(库列表/表列表/扫描记录/扫描详情/看板/报告列表)在存在 PENDING/RUNNING 任务时每 2s 轮询;`onDeactivated`/`onUnmounted` 停止、`onActivated` 恢复/刷新--靠 keep-alive 生命周期而非定时销毁。
2. **二次确认**:所有删除、取消、批量扫描都过 `ElMessageBox.confirm`。
3. **只读筛选模式**:外部带 `tagId` 进入表列表时,写操作(扫描/打标/AI 描述/生成描述)全部隐藏,顶部 alert 一键清除恢复。
4. **安全边界**:编辑态秘密字段不回填;401 全局踢回激活页;导出文件含加密密码有警示文案;`/api/license/*` 与 `/api/heartbeat` 不参与授权拦截。
5. **路由-页签联动**:页签标题由 `resolveTab(route)` 动态推导,页签 key 决定关闭后的去向(扫描页签 → 来源数据源页签)。
6. **数据源名兜底解析**:库/表/扫描等页面在面包屑与页签标题中展示数据源名,来源优先级为 URL `?name=` → 内存缓存 `dsNames` → `ensureDsName(id)`(`stores/tabs.js`)。后者按 id 从 `/datasources` 列表补全并回写缓存(同 id 并发只发一次请求,失败静默返回空串,维持「数据源 ${id}」兜底显示);刷新/直达 URL 无 `?name=` 时,由页面挂载/激活时调用 `ensureDsName` 恢复真名并 `syncTab` 刷新页签标题。
