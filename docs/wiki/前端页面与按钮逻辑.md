# 前端页面与按钮逻辑

> dq-tool 项目文档,索引见根 [AGENTS.md](../../AGENTS.md)。本文覆盖前端(web/)页面结构、页面间导航与各页面按钮/交互控件的触发逻辑,是改前端代码前先读的导航手册。

## 总体框架

- 技术栈:Vue 3 + Element Plus + vue-router + axios(`baseURL=/api`)。API 层统一走 `web/src/api/index.js` 的 axios 实例:401(非 license 接口)整页跳 `/activate` 并清 keep-alive;blob 错误体解析回 JSON 弹 message;统一 `ElMessage.error`。
- 布局(App.vue):`/activate` 为全屏独立页不渲染框架;其余页面 = 左侧侧边栏(一级功能导航,App.vue 内定义;默认 200px,右缘手柄可拖拽调宽,最小 160px、最大视口 40%,存 `localStorage('dq-sidebar-width')`,可收起为 64px)+ 右侧(48px 头部[当前一级功能名 + 三档主题切换,自动/浅色/深色,存 `localStorage('dq-theme')`] + 页签栏 + 主内容(`keep-alive` 缓存 20 个,key=`route.fullPath`))。
- 侧边栏「数据源」为**可展开树**(el-sub-menu):子项「全部数据源」(→ 列表页)+ 各数据源(带 DbTypeIcon,点击直接进该数据源库列表;项右侧有编辑图标,点击跳列表页并直接打开该项的编辑框),设了分组的数据源先按分组成组——命名分组渲染为可折叠子菜单(文件夹图标+数量角标,下钻时自动展开所在分组),未分组平铺在最后;标题右侧 ⋮ 下拉提供「新增数据源 / 导入配置 / 导出配置(JSON)」。数据源列表由 App.vue 拉取 `/api/datasources`(进入数据源相关页、展开子菜单时刷新,失败静默维持旧列表);排序与主界面卡片一致——收藏的在前、同收藏按收藏时间倒序(共用 `utils/dsFavorites.js`,主界面切换收藏时经 `dq-ds-favorites-changed` 事件即时刷新);数据源页新增/编辑/删除/导入后经 `dq-ds-list-changed` 事件(`utils/dsListChanged.js`)通知侧边栏即时重拉,分组结构变更不等下次路由进入;列表限高 40vh 滚动,「全部数据源」固定不随列表滚动。
- 侧边栏「数据源」操作下拉通过 `tabState.pendingDsDialog`(stores/tabs.js)传递命令,数据源页消费后清空并打开对应对话框;菜单项右侧编辑图标同理走 `tabState.pendingDsEditId`(写 id + 跳 `/datasources`,数据源页消费后按 id 找行开编辑框)。**不用路由 query**——App.vue 的 keep-alive 以 `route.fullPath` 为 key,query 变化会导致组件重挂载、弹框状态丢失。
- 侧边栏高亮:`activeNav` 按路由前缀推导——`/datasources` 高亮「全部数据源」,`/datasources/:id/*` 高亮对应数据源项并自动展开树,`/scans*` 高亮「扫描记录」(任务域),其余一级页各自命中;`/license-admin` 仅 `status.admin && features 含 license_admin` 显示入口。
- 页签栏 `v-if="tabState.tabs.length"`:「数据源」一级页不占页签,全部页签关闭后整条隐藏。
- **授权功能控制**:侧边栏一级导航按 `/api/license/status` 的 `features` 过滤——业务功能(数据源/扫描记录/标记统计/AI 统计/报告列表)恒显示;「运行日志」需授权码含 `logs`;「授权码管理」需 `status.admin` 且含 `license_admin`(详见 [授权码](授权码.md) 功能列表)。更换授权码成功后 `markActivated()` 广播 `dq-license-changed` 事件,App.vue 监听后整体刷新侧边栏(重取状态 + 数据源树);若当前页因新授权失去入口权限(如正在运行日志页而新码不含 logs)主动跳回首页

### 页签系统(`stores/tabs.js`)——理解页面关系的前提

> 「数据源」一级页(列表)由侧边栏导航直接切换,**不占页签**;数据源之外的其余一级功能页(扫描记录/标记统计/AI 统计/报告列表/抽样导出/运行日志/授权管理)**各占一个固定页签**——侧边栏点击时已存在则定位、不存在则追加到最右侧;页签同时管理工作流下钻页。

| 页签 | key | 行为 |
|---|---|---|
| 数据源外一级功能页 | `page-{path}` | 可关闭;扫描记录/标记统计/AI 统计/报告列表/抽样导出/运行日志/授权管理各占 1 个,标题固定 |
| 每数据源 1 个 | `ds-{id}` | 可关闭;库列表→表列表→扫描记录在**同一页签内下钻**,标题随路由动态变(由 `resolveTab` 推导) |
| 每扫描任务 1 个 | `scan-{jobId}` | 可关闭;**关闭时优先跳回其来源数据源页签**(`scanDsIds` 缓存),而非相邻页签 |
| (空态兜底) | — | 关闭最后一个页签后 `activeKey=''`,跳回 `/datasources`(侧边栏可重新下钻) |

### 路由守卫(`router/index.js`)

- 除 `/activate` 外每次导航先查 `GET /api/license/status`(Promise 缓存,并发共享);未激活/已过期 → `/activate`;激活成功后 `markActivated()` 更新缓存避免守卫重复查询。
- `/diagnostics`(系统诊断)与 `/activate` 一样直接放行:排错场景常是授权问题本身。
- `/license-admin` 额外要求 `status.admin`,非管理员回 `/`。
- 各页包屑用 `Breadcrumb.vue`;「返回」按钮走 `utils/back.js`:有浏览历史 `router.back()`,无历史才兜底 push。

```
  /tags         标记统计

      (数据源页签内)            │      ├─ 已扫描 → ?jobId= 字段统计(同页签)
                                │      └─ 未扫描 → /datasources/.../tables/:tableName  字段元数据(页签内)
                                └→ /datasources/:id/schemas/:schema/scans  扫描记录
                                        └→ /scans/:jobId  扫描详情(新开扫描页签)
                                               └→ /scans/:jobId/tables/:name  字段统计(旧路由兼容)
/dashboard  扫描记录 ─→ /scans/:jobId
/tags  标记统计 ─→ 表列表?tagId=&tagName=(只读筛选模式)
/ai-usage  AI 统计(指标卡 + 消耗柱状图 + 场景分布 + 最近调用)

/sample-exports 抽样导出 ─-> 任务明细 drawer(数据源导入明细 + 逐表小进度)/下载 zip/打开目录

/diagnostics    系统诊断 ─→ /scans/:jobId(失败任务链接)
```

## 逐页面按钮逻辑

### 首页/数据源管理 `Datasources.vue`(`/datasources`)

卡片网格展示全部数据源;未设密码的卡片红色警示 + 禁用浏览。**每次切回页签都刷新**(`onActivated`)。工具栏带搜索框(匹配名称/主机/用户名/类型);卡片右上角星标为收藏(本地偏好,按 id 存 `localStorage('dq-ds-favorites')`),收藏的卡片排最前、同收藏按收藏时间倒序(后收藏的在前,逻辑在 `utils/dsFavorites.js`,与侧边栏共用)。

| 按钮/控件 | 触发行为 |
|---|---|
| 搜索框 | 前端过滤卡片(名称/主机/用户名/类型),无匹配显示空态 |
| 收藏星标 | 切换收藏 → 写 `localStorage('dq-ds-favorites')`,卡片收藏优先 + 收藏时间倒序排序 |
| 导出 | 默认全选 → 弹导出框 → `downloadFile('/api/datasources/export?ids=...')` 导出 JSON |
| 导入 | 弹导入框(文件/粘贴两模式),支持 `.json` / Navicat `.ncx` / DataGrip 剪贴板;文件模式选中后先经 `confirmImportFile`(见贯穿性机制 9)识别确认,确认即提交 `FormData POST /datasources/import`,展示 总数/成功/自动改名/失败原因 |
| 新增/编辑 | 数据源编辑弹窗(独立组件 `DatasourceEditDialog.vue`,见通用组件,抽样导出页复用):DataGrip 风格,**常规/SSH隧道/库过滤/高级 4 页签**;编辑态秘密字段(密码/私钥/口令)一律不回填、留空=不修改;SQLSERVER 的 encrypt/trustServerCertificate/sslProtocol 三个连接参数在「高级」页签编辑(默认 true/true/TLSv1.1,兼容老版本 SQL Server),编辑打开时从已存 URL 剥离回填,保存/测试/拉库列表时先剥后拼回 URL;保存 `POST /datasources` 或 `PUT /datasources/:id`(后端同时把抽样导出的连接状态标记清零,回到「未检测」) |
| 测试连接 | `POST /datasources/test`,编辑态带 id,密码/SSH 秘密留空由服务端回落已存值(与 preview-databases 同一套 `mergeStoredCredentials`);失败切回对应页签提示 |
| 删除 | 二次确认 → `DELETE /datasources/:id` → 刷新 |
| 库过滤「加载库列表」 | 编辑态连接未改走 `GET .../databases?all=true`(为空回落 `/schemas?all=true`),否则 `POST /datasources/preview-databases` 按表单实时连接;保存 `PUT /datasources/:id/schema-filter`(全勾/全不勾=不过滤) |
| 卡片拖拽 | 原生 HTML5 drag & drop 把卡片拖到其他分组区块(分组头/卡片网格均可放置,折叠组的头也能接收)改分组 → `PUT /datasources/:id/group`(拖到「未分组」传 null),同组放置忽略;成功后整体重拉并通知侧边栏刷新 |
| 数据库类型下拉 | 自动切默认端口(MySQL 3306 / PG 5432 / DM 5236 / KINGBASE 54321 / OB 2881 / SQLServer 1433 / Oracle 1521 / HIGHGO 5866) |

### 库列表 `Schemas.vue`(`/datasources/:id/schemas`)

表格展示库 + 每库最近扫描状态/进度/标记;有运行中任务时每 2s 轮询统计(标记接口失败保留旧数据)。
SQL Server/Kingbase 多库场景:无数据库下拉,**始终跨库展示**,「库名」拆为**数据库 + 架构(Schema) 两列**——前端逐库拉取 schema/统计后按 数据库+架构 键合并,行内携带所属数据库,扫描/下钻/描述/报告导出均按行内 db 处理(报告导出按数据库分组逐库提交任务);搜索框同时匹配数据库名与架构名。其他方言仍是单列「库名(Schema)」。

| 按钮/控件 | 触发行为 |
|---|---|
| 批量扫描 | 勾选库 → 扫描对话框(与表列表页一致:强制全量/表大小上限/AI 自动打标/生成表描述/并发线程数/空值规则,扫描范围为整库)→ `POST /scans` 逐库提交(tables=null 整库);自动跳过正在扫描的库 |
| 导出 | 下拉:「导出当前列表 / 导出扫描报告 / 导出表结构文档」 |
| 导出→导出当前列表 | `exportListToExcel` 导出当前过滤后的库列表(库名/描述/表数量/占用空间/标记/最近扫描状态时间;多库方言前置「数据库」列) |
| 导出→导出扫描报告 | 勾选则导出勾选库,否则导出全部已完成全表扫描的库(需确认)-> `POST /datasources/:id/report/exports`(跨库勾选时按数据库分组逐库各提交一个任务) -> 成功后询问是否跳「报告列表」页 |
| 导出→导出表结构文档 | 无需勾选,导出数据源下所有白名单过滤后的库的表结构 Word → `downloadFile('/api/datasources/:id/export-dbstruct-word')` 同步下载(实时元数据,缓存优先,未扫描也可导出) |
| 更多→库过滤 | 弹过滤弹窗 → 保存 `PUT /datasources/:id/schema-filter` |
| 库名链接 | 下钻表列表页 |
| 描述-编辑 | 弹窗 → `PUT /schemas/:name/description`(供 Word 报告「实例描述」,留空即清除) |
| 标记块(前 3 个 + "+N") | 点击跳表列表并带 `?tagId=&tagName=` 只读筛选 |
| 扫描(行内) | 同批量扫描的确认+提交;正在扫描的库禁用 |
| 扫描记录(行内) | 跳扫描记录页(从未扫描过则禁用) |
| 搜索框 | 纯前端过滤;多库方言(SQL Server/Kingbase)跨库列表下同时匹配数据库名与架构名 |

### 表列表 `Tables.vue`(`/datasources/:id/schemas/:schema/tables`)

扫描主入口。支持本地筛选(搜索 / 标记多选 OR 逻辑 / 只看空表,`onlyEmpty` 按有效行数=0 过滤)。勾选状态经 `row-key="name"` + `reserve-selection` 固定,搜索/筛选/排序不影响已选表(可搜索定位后单独取消勾选)。

| 按钮/控件 | 触发行为 |
|---|---|
| 开始扫描 | 弹扫描对话框:**强制全量 switch(默认开)、表大小上限(数值+MB/GB,实时提示将跳过的表数)、AI 自动打标复选(默认勾选)、生成表描述复选(默认勾选;AI 相关项未配置大模型时后端自动跳过)、并发线程数(数值,默认填 `GET /scans/defaults` 拉取的配置默认值,留空用配置默认)、空值规则(列名+逗号分隔值)**;提交 `POST /scans`,范围优先级 单表 > 勾选 > 全库;成功跳 `/scans/:jobId?schema=库名` |
| 导出 | 下拉:「导出当前列表 / 导出扫描结果 / 导出扫描报告」 |
| 导出→导出当前列表 | `exportListToExcel` 导出当前过滤后的表列表(表名/注释/标记/描述/引擎/行数/总大小/最近扫描时间,行数与大小取值口径同表格展示);无行时菜单项禁用 |
| 导出→导出扫描结果 | ExportButton(hideTrigger + ref 唤起弹窗选列)→ `GET /datasources/:id/schemas/:schema/export-latest?db=`;每表最近一次表级 DONE 快照(跨任务,不依赖指定任务),无任何 DONE 数据时菜单项禁用(后端 409 兜底) |
| 导出→导出扫描报告 | 单库 `POST /datasources/:id/report/exports`;未扫描时后端 409 拦截(blob 错误体解析出提示) |
| 生成描述(批量) | 勾选表并发 2 逐条 `POST /tables/:name/doc`(130s 超时),汇总成功/失败数 |
| 表名链接 | 已扫描 → `/scans/:jobId/tables/:name` 字段统计;未扫描 → 字段元数据页(旧版 jobId 数字兼容) |
| 描述列 | 无描述显「生成描述」/有描述显刷新图标(都调 `POST /tables/:name/doc`);点文本弹窗编辑 `PUT /tables/:name/doc`(2000 字上限) |
| 打标(行内) | 弹 `TableTagDialog`(见组件) |
| 扫描进度条 | 仅运行中表显示,点击跳扫描详情 |
| **只读筛选模式** | 带 `tagId` 进入时:顶部 alert + 「清除筛选」;隐藏 批量生成描述/开始扫描/打标,表名仍可点 |

### 扫描链路(Scans / ScanDetail / TableColumns / TableColumnsMeta)

| 页面 | 按钮/控件与行为 |
|---|---|

### 统一下载封装 `utils/download.js`

所有「下载/导出」统一走 `downloadFile(apiPath)`(数据源导出、标记导出、扫描 Excel 导出;Word 报告落盘有产物,仍用 `save_report_as` 复制,见报告列表):**桌面端(tauri,`isTauri` 判断 `__TAURI_INTERNALS__`)`invoke save_download_as` 弹原生保存对话框,用户自选保存目录**——Rust 侧 GET 本地后端流式接口写盘,文件名以后端 `Content-Disposition` 为准;浏览器环境无通用选目录 API,保持 `window.open` 默认下载(存浏览器默认下载目录)。

前端组装内容的文本下载(目前仅诊断报告)走 `downloadText(filename, text, mime)`:Blob + `a[download]`,浏览器与 Tauri webview 均可用。

### 通用列表导出 `utils/listExport.js`

各列表页「导出 Excel」按钮统一走 `exportListToExcel(filename, headers, rows[, sheetName])`:POST `/api/list-exports` 提交所见表格数据拿一次性 token,再走 `downloadFile` GET 下载(机制详见「扫描与Excel导出」);`cellText` 负责把单元格值归一为展示字符串(null/undefined → 空串)。

## 贯穿性交互机制

1. **轮询纪律**:扫描相关页(库列表/表列表/扫描记录/扫描详情/报告列表;其中「扫描记录」含库内扫描记录页与全局扫描记录页)在存在 PENDING/RUNNING 任务时每 2s 轮询;`onDeactivated`/`onUnmounted` 停止、`onActivated` 恢复/刷新--靠 keep-alive 生命周期而非定时销毁。
2. **后端就绪轮询**(main.js):后端启动时先绑定端口提供静态页面(首页秒出),共享内核(H2 建表/迁移 + 中断恢复)随后完成;应用挂载前轮询 `/api/health`(500ms 间隔、60s 超时兜底),轮询到 200 才 mount——期间页面停留在 index.html 的启动占位,业务视图不会在就绪前挂载导致接口报错刷屏。**启动占位(2026-08 启动优化)**:品牌 logo + 三阶段步骤条(加载配置/启动服务/初始化数据),未就绪的 503 响应带 `stage` 字段(`StartupStage`),轮询时按阶段点亮"已过=绿、进行中=蓝呼吸"步骤,等待有动效反馈;就绪后 `#app` 被 Vue 替换,占位消失。
3. **二次确认**:所有删除、取消都过 `ElMessageBox.confirm`;扫描入口(库列表/表列表)统一走扫描对话框(el-dialog,两页字段一致)。
4. **弹窗禁 Esc 关闭**:所有 `el-dialog` 统一带 `:close-on-press-escape="false"`、所有 `ElMessageBox` 调用带 `closeOnPressEscape: false`——弹窗只能点右上角叉叉或底部按钮关闭,任何键盘事件不得关弹窗;新增弹窗时必须遵守。
5. **只读筛选模式**:外部带 `tagId` 进入表列表时,写操作(扫描/打标/AI 描述/生成描述)全部隐藏,顶部 alert 一键清除恢复。
6. **安全边界**:编辑态秘密字段不回填;401 全局踢回激活页;导出文件含加密密码有警示文案;`/api/license/*` 与 `/api/heartbeat` 不参与授权拦截。
7. **路由-页签联动**:页签标题由 `resolveTab(route)` 动态推导,页签 key 决定关闭后的去向(扫描页签 → 来源数据源页签)。
8. **数据源名兜底解析**:库/表/扫描等页面在面包屑与页签标题中展示数据源名,来源优先级为 URL `?name=` → 内存缓存 `dsNames` → `ensureDsName(id)`(`stores/tabs.js`)。后者按 id 从 `/datasources` 列表补全并回写缓存(同 id 并发只发一次请求,失败静默返回空串,维持「数据源 ${id}」兜底显示);刷新/直达 URL 无 `?name=` 时,由页面挂载/激活时调用 `ensureDsName` 恢复真名并 `syncTab` 刷新页签标题。
9. **导入文件识别确认**(`utils/importFileIdentify.js`):三个文件导入入口(数据源/扫描记录/标记与描述)选中文件后一律先走 `confirmImportFile(file, currentFeature)`——按内容识别文件归属(三种 JSON 导出靠顶层 `app` 字段 `dq-tool` / `dq-tool-scans` / `dq-tool-annotations` 区分,Navicat `.ncx` 与 DataGrip 剪贴板按 XML 特征),弹窗告知"识别到该文件是 XX(内容摘要)":归属当前功能则等用户「确认导入/取消」;不属于当前功能、版本不兼容或无法识别时弹提示阻断(拿错文件时指路到正确入口),不发请求。新增导入入口时必须接入。
