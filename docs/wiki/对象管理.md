# 对象管理(数据目录)

按数据源隔离的目录树:把业务表按主题域组织成目录,目录下挂载表(四元组定位),挂载表可登记相关的关系表清单。纯本地元数据管理,不连业务库。

## 数据模型(V36,rel_kind 列 V37/V38)

- `object_dir`:目录。`datasource_id + parent_id + name` 唯一;`parent_id=0` 表示根下的顶层目录(根是虚拟节点,不落库,保证唯一索引可用)。目录按数据源隔离,不同数据源各有独立的树
- `object_table`:目录下挂载的表。`dir_id + db_name + schema_name + table_name` 唯一;`db_name` 空串兜底口径与 manual_collect 一致(无库概念方言存空串);`remark` 为挂载备注;`rel_kind` 为挂载表与目录的关系类型(V37,`INCLUDE`=包含 / `ASSOC`=关联,NULL=未指定),在目录图 目录→表 连线上展示
- `object_table_rel`:挂载表登记的关系表。`object_table_id + 四元组` 唯一;`remark` 为关系备注(如关联字段/业务含义);`rel_kind` 为关系表与挂载表的关系类型(V38,口径同上),在目录图 挂载表→关系表 连线上展示
- 无外键(同 manual_collect 惯例):数据源删除后目录树保留;删除目录的级联由 service 层在 tx 内完成

## 语义

- **组树**:`ObjectCatalogService.loadTree(datasourceId)` 一次拉三类记录内存组树,返回虚拟根节点(id=0、name 空串、tables 恒空),真实顶层目录在其 `children` 下;目录按 name 排序,表按 tableName 排序。挂载表/关系表的 `comment` 从 `meta_table` 缓存按 (db, schema) 分组批量补齐,缓存未覆盖给空串
- **新建/重命名目录**:同级(同数据源同父目录)重名 400;`parentId` 可空(null=根,等价 0,即挂在虚拟根下的顶层目录),`parentId>0` 时父目录必须存在且同属该数据源
- **删除目录**:级联删除全部子孙目录及其挂载/关系记录(子孙 id 拉回内存按 parentId BFS 收集,tx 内按 关系→挂载→目录 顺序删),返回 `{dirs, tables, rels}` 级联统计
- **挂载表**:目录不存在 400;同目录同四元组重复挂载幂等跳过,不报错。接口为批量(一次同 db/schema 多张表,列表内按表名去重),逐表可选关系类型 `relKind`(INCLUDE/ASSOC,空白=null,非法值 400),返回 `{mounted, existing}` 新插/跳过统计;重复挂载时 `relKind` 非空且与现值不同则更新(提供修正入口),空不覆盖现值
- **取消挂载**:tx 内级联删除其关系记录;挂载不存在 400
- **登记关系表**:挂载记录不存在 400;不允许指向挂载表自身(同四元组,db null/空串同口径);批量与幂等口径同挂载,逐表可选关系类型 `relKind`(重复登记时修正口径同挂载)。前端弹窗 schema 锁定为挂载表所在库/schema(自动选中不可改,关系表默认与挂载表同 schema),清单排除挂载表自身
- 异常约定同全局:`IllegalArgumentException` → 400

## 页面布局(前端)

- **左侧目录树常驻**(刷新/新建根目录/节点悬浮操作),选中目录驱动右侧内容实时联动;右侧 `el-tabs` 三页签:
  - **列表**:当前目录直接挂载的表(行内展开关系表子表,支持添加关系表/取消挂载)
  - **关系图**:`ObjectGraphCanvas` 目录子图(G6 mindmap/compact-box),**根节点=选中目录**(传 `rootDir`;不传则回退旧的「数据源虚拟根+整树」兼容模式),显示开关(布局方向/字段/字段数/类型/名字口径)在画布工具栏
  - **图谱**(`ObjectDirGraphPane`):选中目录**含子目录**的目录 + 挂载表 + 登记关系表的关系图(复用表详情「图谱」页签的 `TableGraphCanvas` 圆形节点星型图,走 d3-force 力导向布局(知识图谱口径:目录大节点下挂小节点表,不预设坐标、仿真从零自动编排);节点尺寸分档 锚点目录 72 > 子目录 48 > 表 32(挂载表与关系表同尺寸,仅颜色区分)(`sizes` prop);边长分档(边数据 `distance` 字段,语义 = **可见连线长度/两圆边缘间距**,画布内部加回两端半径换算成 d3-force 的圆心距目标——否则大节点半径吃掉边长、短边还会被 collide 最小圆心距顶开,导致长短边一样长;同理 collide padding 不能大于短边目标):**S1 = 目录↔目录距离**(默认 120,拉开簇间距)、**S2 = 目录→挂载表 / 挂载表→关系表距离**(默认 60),S1 = 2 × S2;长边弱强度 0.15(主干摊开)、短边强强度 0.8(卫星节点向目录聚拢),叶子节点斥力大,collide 按节点尺寸防重叠,节点可拖拽、松手仿真回温自动归位;工具栏设置图标按钮展开左下角调试面板,两个数字输入框实时调 S1(60–600)/S2(20–300),「重置」恢复默认值,调定后固化进 `ObjectDirGraphPane` 的 `LINK_S1_DEFAULT`/`LINK_S2_DEFAULT`;节点/连线恒定 节点在上(zIndex 1/0 显式给值:drag-element-force 拖拽开始 G6 会 frontElement 置顶被拖节点且不归位,此后异步追加的边若吃默认层级计算会被抬上节点层——线压节点、点名称选不中;显式 zIndex 让新边不受拖拽置顶污染);目录本身也是节点——选中目录为锚点居中、warning 色,关系表节点 success 色与挂载表(主题色)区分;父目录→子目录、目录→挂载表、挂载表→登记关系表用 MOUNT 灰色实线边;ER 推导关系边用 `GET /api/relations`,按 (库,schema) 分组拉取后过滤两端都在目录表集合(含关系表)内的边,仅已确认边,候选关系不混入图谱;只读,单击节点深描边选中 + 高亮其直接相连节点与沿归属层级到中心锚点路径上的节点(高亮/选中走画布 repaint 原地刷样式,不重建不重跑仿真;其余节点/边降透明度,点画布空白取消)并开右上角悬浮面板(表节点=注释/表名/字段列表懒拉/查看表详情,目录节点=子树统计,与表详情「图谱」节点面板同款),双击表节点跳字段明细)。已知限制:表节点以表名为键,跨 schema 同名表合并
- 页签懒挂载(`lazy`),已挂载页签切走保持实例(G6 `autoResize` 兜底尺寸,折叠状态不丢)

## API

```
GET    /api/datasources/{dsId}/object-catalog   整棵目录树(虚拟根 ObjectDirNode)
POST   /api/object-dirs                         新建目录 {datasourceId, parentId?, name} → {id}(parentId 可空,空=根,等价 0)
PUT    /api/object-dirs/{id}                    重命名 {name}
DELETE /api/object-dirs/{id}                    删除目录(级联)→ {dirs, tables, rels}
POST   /api/object-dirs/{id}/tables             批量挂载表 {dbName?, schemaName, items[{tableName, relKind?}], remark?} → {mounted, existing}
DELETE /api/object-tables/{id}                  取消挂载(级联删关系)
POST   /api/object-tables/{id}/relations        批量登记关系表(请求体同挂载)→ {mounted, existing}
DELETE /api/object-table-relations/{id}         移除关系表
```

### 目录树响应结构

```jsonc
{
  "id": 0, "datasourceId": 1, "parentId": 0, "name": "",   // 虚拟根
  "tables": [],
  "children": [
    {
      "id": 10, "datasourceId": 1, "parentId": 0, "name": "业务域",
      "children": [ /* 子目录,同结构递归 */ ],
      "tables": [
        {
          "id": 100, "dirId": 10, "dbName": "", "schemaName": "public", "tableName": "cust",
          "comment": "客户信息表",          // meta_table 缓存补齐,未覆盖为 ""
          "remark": "挂载备注",
          "relKind": "INCLUDE",            // 关系类型:INCLUDE=包含 / ASSOC=关联,未指定为 null(目录图连线上展示)
          "relations": [
            { "id": 200, "dbName": "", "schemaName": "public", "tableName": "ord",
              "comment": "订单表", "remark": "关系备注" }
          ]
        }
      ]
    }
  ]
}
```
