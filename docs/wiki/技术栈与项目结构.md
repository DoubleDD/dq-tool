# 技术栈与项目结构

> dq-tool 项目文档,索引见根 [AGENTS.md](../../AGENTS.md)。

## 技术栈

- 构建:Gradle 多模块(根 wrapper 9.2.1),子模块 `common`(共享业务内核,Kotlin,见 [common/AGENTS.md](../../common/AGENTS.md))、`server`(Java Javalin Web 壳),共享依赖版本统一在 `gradle/libs.versions.toml`;`web/` 与 `tauri/`(Tauri 2 桌面壳,另需 cargo)为独立 npm 工程,不纳入 Gradle
- 后端(server/):Java 25、Javalin 7(内嵌 Jetty 12 ee10)+ hibernate-validator + snakeyaml + Logback 的薄壳,只含入口/配置加载/Web 路由/桌面生命周期;**业务逻辑全部在 common 模块**(Kotlin),由 `config/KernelConfigAdapter` 把 yml 配置映射为内核 `AppConfig`,`web/WebServer` 装配内核 `ServiceEnv`;Jackson 3(`tools.jackson` + KotlinModule)只在 Web 层序列化内核 Kotlin data class。2026-08 已从 Spring Boot 4.1 迁移(方案见 `docs/plans/de-spring-javalin-改造方案.md`),同月业务代码下沉 common 后移除 spring-jdbc
- 前端:Vue 3 + Vue Router + Element Plus + axios + CodeMirror 6(SQL 过滤输入的高亮/补全,`SqlInput.vue` 精简封装),Vite 5 构建(无 TypeScript、无状态库,`stores/tabs.js`/`stores/theme.js` 为自写简易 store);明暗双主题:`html.dark` 类 + EP 官方暗色变量包,设计令牌与页面骨架类集中在 `src/style.css`,头栏右侧三档循环切换(自动跟随系统 prefers-color-scheme 并监听变化 / 浅色 / 深色,默认自动),选择存 localStorage(`dq-theme`),UI 颜色一律走 `--el-*`/`--dq-*` 变量不写死色值(用户可配的标记色、数据库图标品牌色除外)
- 测试:JUnit 5 + AssertJ + Testcontainers(MySQL 8 / PG 15 / SQL Server 2019);不使用 Spring 测试框架,集成测试手动装配
- 交付:shadow fat jar(内嵌前端);jpackage 生成 macOS dmg / Linux deb+rpm 安装包与 Windows 免安装 zip(均内嵌 JRE)

  **画布数据更新分层经验(结构变化 vs 样式变化,力导向布局下尤其关键)**:
  - 底座 deep watch `data` → `refresh()`(setData+render,重跑布局);力导向布局(d3-force)下 render 会等仿真收敛(默认 alphaMin 0.001 ≈ 300 tick ≈ 5s,期间画布隐藏空白),所以**凡是会重跑布局的重建都必须只由结构变化触发**
  - 模式:调用方把图数据拆成「结构数据」(节点/边集合、坐标、尺寸——不含高亮/选中/节点颜色等瞬时样式)喂给底座;**高亮/选中/节点填充色这类纯样式变化走 `repaint()`**(setData+draw,只重算样式,不跑布局、不动仿真,原地瞬时更新;setData 对 style 浅合并,数据不带 x/y 不丢仿真中的位置);结构重建后样式被重置,借底座 `rendered` 事件补刷一次样式覆盖层,用签名判重防 rendered↔repaint 死循环(参考实现:`TableGraphCanvas` 的 `buildData(hl, sel)` 参数化 + `applyOverlay`)
  - 力导仿真提速:d3-force 收敛时长由 alphaMin/alphaDecay 决定,`alphaMin: 0.05, alphaDecay: 0.06` 可把 5s 压到 <1s,视觉无损;拖拽回温(drag-element-force 的 alphaTarget 0.3)不受影响
  - 渲染口径参数若同时要出现在结构数据里(如节点填充色:改色要原地刷、筛选重建的首帧又必须直接是最终色,不能先画默认色再由覆盖层过渡),用**非响应式快照**:普通变量存值 + `watch(..., { flush: 'sync' })` 跟住来源 prop,结构数据读这个变量——既不登记依赖(改色不触发重建),重建时读到的又必然是最新值(参考实现:`TableGraphCanvas` 的 `structColors`)
  - 力导布局必须开动画渲染(底座 `animated` prop,调用方按布局需要传):关动画路径会 layout.stop() 且不挂 onTick,仿真死后拖拽回温画面不更新(表现为「节点拖不动」)
  - G6→@antv/layout 的模型转换(layoutAdapter)只保留边 id/source/target、节点 id/坐标,**自定义字段到不了布局回调**——边长/权重分档要在布局回调里按边 id/节点名闭包回查业务数据(参考 `TableGraphCanvas` 的 `edgeDistanceById`/`leafNames`)
  - **元素层级要显式给 zIndex(节点 > 边),别吃 G6 默认计算**:drag-element/drag-element-force 拖拽开始会 `frontElement` 把被拖节点永久置顶(zIndex=max+1,不归位),此后新增边的默认层级(相连节点 zIndex 最大值 −1)沾到被拖节点就会升到与节点同级,后插入渲染压过节点——线盖节点、边吞点击(点名称选不中);显式 节点 1/边 0 后新边不再受拖拽置顶污染(参考 `TableGraphCanvas` 的 `buildData`)
  src/api/index.js           axios 封装(统一错误弹窗;401 非授权接口时整页跳 /activate),非 API 方法集合
  src/router/                beforeEach 授权守卫(原生 fetch 查 /api/license/status 并缓存,避免与 axios 循环依赖) src/stores/ src/utils/ src/assets/dbicons/(数据库 SVG 图标)
docker-test-env/             手动验证用的 SQL Server / Oracle 23c / Oracle 11g XE docker-compose(非 CI 使用;11g XE 镜像仅 amd64,Apple Silicon 走 Rosetta)
scripts/                     package-mac.sh / package-win.bat / package-linux.sh(jpackage 打包,--main-class com.example.dq.DqApplication)、package-tauri-{mac.sh,win.bat}(Tauri 套壳的 dmg / Windows NSIS 打包)、LicenseKeygen.java(授权码签发工具,纯 JDK 源码模式运行;Makefile 提供 make license-keypair / make license 快捷命令)、make-word-template.py / make-word-template-ch234.py(Word 报告模板第一章 / 封面+二~四章 poi-tl 标签改造的一次性工具,需 python-docx)
