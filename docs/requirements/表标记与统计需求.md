# 表标记与统计功能 — 需求文档

> 状态:需求已确认,待实施
> 来源:客户对话梳理(2026-08-06,经 /grill-me 逐项确认)
> 关联文档:无(实施时在 `docs/plans/` 新建实施计划)

## 一、背景

客户需要在 dq-tool 中增加「表标记」功能:对表打全局标记(空表自动标记、用户自定义业务标记),并提供两个统计视图(库维度统计、标记维度统计),用于按业务口径盘点数据资产。

原始需求对话:

> a: 你再给我增加一个类似于标记的功能 这个标记是全局的 可以对表打标记 比如默认扫描后 空表直接打标记上 然后我可以编辑这个标记 比如我可以增加 基础水利对象表 防洪业务表 水资源业务表等
> a: 我标记完以后 可以在这里 看到对应的统计 比如每个库下面的空表多少个 水利业务表多少个 水利对象表多少个 这样的 然后再点击可以根据我需要的内容筛选出来
> a: 然后我也可以按照标记 有单独一个统计页面 比如可以看到 我对应标记的水利对象表有多少个 然后在哪个数据源下 然后哪个库里分别多少个 然后累计的表多少 行多少 列多少 数据量多少
> b: 单表要支持多标记吗
> a: 可以 多标统计两次

## 二、术语

| 术语 | 含义 |
|---|---|
| 标记 (Tag) | 打在表上的业务标签,全局共享,带名称与颜色 |
| 空表标记 | 特殊标记,由扫描结果自动驱动,用户不可干预 |
| 表标识 | `数据源 + 库 + 表名`,每张物理表独立 |

## 三、功能需求

### 1. 标记体系

- 粒度:`数据源 + 库 + 表名`。同名表在不同数据源/不同库视为不同表,各自打标
- 作用域:全局,跨所有数据源可用
- 属性:名称 + 颜色。名称全局唯一,不允许重名
- 多标记:一张表可同时拥有多个标记
- 管理入口:表列表的打标弹窗,集中提供 新建 / 改名 / 改色 / 删除
- 删除标记:已打上该标记的表自动解除,无残留
- 重命名标记:存量表的标记自动跟随新名称

### 2. 空表标记(特殊标记)

- 扫描完成后自动跟随扫描结果:表为空 → 自动打上「空表」;扫描发现非空 → 自动摘除
- 无编辑入口,用户不可手动干预(不存在于打标弹窗的可选列表中)
- 参与所有统计,与其他标记并列展示

### 3. 库维度统计(现有「库列表」页)

- 每个库行:标签块平铺展示各标记数量(色点 + 标记名 + 数量),放不下时折叠为「+N 更多」
- 点击标签块 → 复用现有表列表页并应用过滤条件(该库 + 该标记),得到只读表列表
- 表数为计数,不依赖扫描;行数/列数才使用扫描快照

### 4. 标记维度统计页(独立页面)

- 布局:左侧标记列表(色点 + 名称 + 表数),点选切换;右侧展示该标记的分布
- 顶部指标卡:当前标记的 总表数 / 总行数 / 总列数,外加「标记覆盖表数(去重)」——多标记导致各标记表数相加 ≠ 实际打标表数,用去重总数兜底解释
- 分布表格:每行一个库(数据源、库名、表数、行数、列数),可排序,底部「合计」行
- 行数/列数取最近一次扫描快照;未扫描过的表显示「—」,不计入累计
- 分布表格中的数字可点击 → 筛出只读表列表

### 5. 多标记统计口径

- 按标记重复计入:一张表打了多个标记时,在每个标记的统计中均 +1
- 「标记覆盖表数(去重)」仅展示,不做其他去重处理

### 6. 数据存储

- 标记定义 + 表标记关系存本地 H2,与数据源连接信息同一文件库

## 四、已确认决策(评审问答记录)

| # | 问题 | 决策 |
|---|---|---|
| Q1 | 标记粒度 | 数据源 + 库 + 表名,每张物理表独立打标 |
| Q2 | 空表自动标记机制 | 自动跟随扫描结果,用户不可干预 |
| Q3 | 多标记统计口径 | 重复计入 + 展示去重后的实际表总数 |
| Q4 | 「累计数据量」含义 | 就是行数总和(原话歧义已澄清);统计页指标为 表数/行数/列数 三项,「数据量」不单独成列 |
| Q5 | 标记删除/重命名 | 删除自动解除引用;重命名存量表自动跟随 |
| Q6 | 统计数字来源 | 最近一次扫描快照;未扫描表行数显示「—」 |
| Q7 | 点击筛选出的列表 | 只读,仅查看 |
| Q8 | 标记创建与属性 | 表列表里直接新建;带颜色;数据存本地 H2 |
| Q9 | 库维度统计位置 | 现有「库列表」页,每个库行展示标记数量 |
| Q10 | 独立统计页选标记方式 | 左侧固定标记列表,点选切换右侧分布 |
| Q11 | 分布呈现 | 表格(每行一个库,可排序) |
| Q12 | 累计指标位置 | 顶部指标卡 + 表格底部合计行 |
| Q13 | 标记管理入口 | 打标弹窗内集中管理(新建/改名/改色/删除) |
| Q14 | 库行标签块形态 | 平铺 + 折叠「+N 更多」,点击可筛选 |
| Q15 | 标记重名 | 不允许,按名称查重 |

## 五、范围外(本期不做)

- 对「库」或「数据源」打标记(仅表)
- 多用户共享/权限(单机工具,数据本地存储)
- 统计结果导出 Excel(客户未提出,导出能力已具备,后续可低成本加上)
