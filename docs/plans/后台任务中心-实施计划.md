# 后台任务中心(关系推导 + 数据比对)实施计划

> 状态:**已实施**(2026-09-14 随 2.0.7 发布)。关联 wiki:[ER 关系推导](../wiki/ER关系推导.md)、[数据比对](../wiki/数据比对.md)、[前端页面与按钮逻辑](../wiki/前端页面与按钮逻辑.md)。

## 背景与问题

关系推导(`RelationInferService`)与数据比对(`CompareService`,含小时级的列级模式)后端都已是异步任务 + 1s 轮询,但进度可视性绑死在各自页面上:

- 推导进度只在 `RelationInferDialog` 打开时可见,关闭弹窗即停轮询且「重开不追溯」(`RelationInferDialog.vue` 注释明确任务在后端继续跑,但重开是全新表单);
- 比对进度只在 CompareTasks/CompareDiff 页签内轮询,`onDeactivated` 即停,离开页签彻底失联;
- 两者完成/失败均无全局通知,必须回到对应页面查看。

## 目标 / 非目标

- 目标:提交后可关弹窗/切页随便走;头栏随时可见进行中的后台任务与进度;终态弹通知(可点击直达结果现场,留痕通知中心铃铛);推导弹窗支持同表任务现场恢复。
- 非目标:比对取消(后端无此语义,CANCELED 仅预留态,属独立特性);扫描/元数据同步/报告导出接入(注册表留扩展口,后续各写一个适配器);应用关闭后的系统级推送。

## 方案概述

```
RelationInferDialog ──POST /relation-infer──▶ 单线程守护(不变)
CompareNew ──POST /compare-jobs──▶ 线程池(不变)
      │                                     │
      ▼                                     ▼
stores/backgroundTasks.js(跟踪器) ◀──1s 轮询── GET /relation-infer-jobs/active(新增)
      │                                    └─ GET /compare-jobs/active(新增,瘦出行)
      ├──▶ App.vue 头栏指示器(铃铛旁,chip)→ BackgroundTasksDrawer(按 kind 分区)
      └──▶ 终态 transitions → utils/notify.js(小扩 title/onClick)弹通知+留痕
```

## 后端改动(common 内核 + server 壳层,无 Flyway 迁移)

1. **推导任务引入 PENDING 态(零迁移)**:`relation_infer_job.status` 列默认 `'RUNNING'`(V35),INSERT 显式传 `PENDING`;守护线程 `runInfer` 起手置 `RUNNING`(`markRunning` 同步记 `started_at=CURRENT_TIMESTAMP`,started_at 语义从「提交时刻」改为「开始执行时刻」,提交时刻看 `created_at`);`failRunningOnStartup` 清扫口径 `WHERE status IN ('PENDING','RUNNING')`。
2. **`GET /api/relation-infer-jobs/active`**:`RelationInferJobRepository.listActive()`(非终态任务,id 升序)+ `RelationInferService.listActiveJobs()` + `RelationController.listActiveJobs` + 路由(声明在 `/{id}` 之前)。继承既有激活校验。
3. **`GET /api/compare-jobs/active`**:`CompareRepository.listActiveJobs()`(`WHERE status='RUNNING'`)+ 目标完成计数 `countActiveTargets()`(一次 GROUP BY:每任务 目标总数/非运行数,目标终态口径 DONE+FAILED)+ 瘦出模型 `CompareJobActiveView`(不含比对字段 JSON/目标明细/数据源名解析,1s 轮询不负重;`progressPercent` 复用 totalUnits/doneUnits 口径)+ `CompareService.listActive()` + `CompareController.listActive` + 路由。注意:该前缀走 compare 授权校验,未授权实例跟踪器静默跳过(容忍 403)。

## 前端改动

1. **`utils/notify.js` 小扩**:`show(type, message, options)` 支持 `options.title`(默认维持「操作成功/失败」)与 `options.onClick`(传给 ElNotification,点击整条通知触发);留痕 title 用同一口径。
2. **`stores/backgroundTasks.js`(新增,模块级单例)**:kind 注册表(每种任务 ~30 行适配器:fetch/isTerminal/toRow/notify/link);单 poll 循环——存在活动任务时 1s 一轮 `Promise.all` 拉各 kind active 接口,终态即停、零任务零开销;App 启动先拉一次,兜住「提交后刷新页面」;单 kind 故障(如 compare 403)静默跳过不炸循环。终态检测:上一轮仍在 active、本轮消失的任务回源详情定 DONE/FAILED 弹通知;`ackTask(kind,id)` 登记表——页面自行消化终态(推导弹窗/CompareTasks/CompareDiff)先 ack,跟踪器跳过已 ack 的不再弹(1s 轮询同窗内可能有漏网,属可接受 race,不追求强一致)。
3. **`App.vue`**:头栏铃铛旁加常驻任务中心图标(列表图标,任何时候可见,角标计数活动任务,点击开抽屉)+ 后台任务 chip——单任务显示「标签 · 阶段 百分比」,多任务显示「后台任务 ×N」,同样点击开抽屉;挂载时启动跟踪器。
4. **`components/BackgroundTasksDrawer.vue`(新增)**:按 kind 分区(关系推导/数据比对),行 = 定位(db.schema + 锚点表/基准表)+ 阶段中文 + 进度条 + 耗时(`utils/format.js formatDuration`)+ 比对行额外「目标 done/total」;点击行 router.push 直达:推导 → 表字段明细 `?tab=er`(带 `db` query),比对 → `/compare/:id/diff`(页签体系已支持每任务一页签)。
5. **`RelationInferDialog.vue`**:提交成功 `watchTask('relation-infer', jobId)`;打开时若跟踪器存在同(数据源/库/schema/锚点表)活动任务 → 直接进入 running 阶段续传该任务(轮询详情接口,弹窗仍自成闭环),footer 提示「关闭弹窗任务继续跑,可从顶部任务入口查看」;自己到达终态时 `ackTask`。
6. **CompareNew.vue**:创建成功 `watchTask('compare', id)`(原有跳列表逻辑不变)。
7. **CompareTasks.vue / CompareDiff.vue**:渲染到 RUNNING→终态 的任务列表/任务详情时 `ackTask('compare', id)`(前者 ack 列表内全部终态任务,后者 ack 本任务),避免与全局通知重复弹。
8. **`api/index.js`**:`listActiveInferJobs()`、`listActiveCompareJobs()`。

## 关键交互口径

- 推导行 stage 映射:`PENDING`→「排队中」;`NAME_MATCH`→「名字匹配」;`SEMANTIC_TABLE`→「语义筛选」;`SEMANTIC_COLUMN`→「字段精判」;`VERIFY`→「值验证」;空→「准备中」。
- 通知文案:推导 DONE「推导完成:锚点表 X,发现 N 条候选关系,点击前往确认」/ FAILED「推导失败:锚点表 X:{error}」;比对 DONE「比对完成:任务名,点击前往差异明细」/ FAILED「比对失败:任务名:{error}」。
- 轮询与项目既有 1s 轮询模式一致,不上 SSE;两个 active 接口都是瘦行,1s 负担可忽略。

## 验证

- `./gradlew :common:compileKotlin :server:compileJava` + `pnpm build`;
- `:common:test` 中推导/比对相关单测不受影响(仓储 insert 语义变化检查既有测试断言);
- 手动冒烟:提交推导后关弹窗 → 头栏 chip 持续刷新 → 抽屉可见进度 → 完成弹通知点击跳 ER 页签;列级比对提交后切走 → 通知 + 跳差异明细;未授权 compare 实例头栏不报错。

## 风险与边界

- compare 前缀授权拦截:跟踪器对 403 静默,chip 只展示有权限的 kind;
- ack race(页面与跟踪器同窗检测):偶发重复一条通知,可接受;
- `started_at` 语义变化(提交时刻→开始执行时刻):任务列表/详情耗时口径不变(仍 startedAt→finishedAt),排队等待不再计入耗时,语义更真实。
