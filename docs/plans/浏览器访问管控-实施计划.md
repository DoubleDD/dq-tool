# 浏览器访问管控(token 门禁)实施计划

> 状态:已存档,待实施(2026-08-10 规划,用户确认后续再做)。
> 背景:应用作为 Tauri 套壳分发,后端 HTTP 端口同时可被浏览器直接打开;要求默认禁止浏览器直接访问,但可用特定参数(`?token=`)访问,Tauri 内无感。

## 目标

- 默认(未配置任何 token):行为完全不变,`java -jar` / jpackage 安装版照常使用。
- 配置了 token:浏览器直接打开 → 403 提示页;带 `?token=xxx` 参数访问 → 正常使用(首次带参访问后种下 Cookie,后续页面跳转/下载/API 均自动放行)。
- Tauri 套壳:每次启动生成随机 token 注入后端,webview 自动携带,用户无感("在 tauri 中没有限制");同时因为 Tauri 实例必定有 token,浏览器直接访问 Tauri 拉起的后端天然被禁。

## 机制总览

- 有效 token 集合 = yml `dq.access-token`(固定,供用户书签/特定参数访问)+ `-Ddq.access-token` / `DQ_ACCESS_TOKEN`(启动注入,Tauri 用),任一非空即开启管控。
- 请求放行条件(三选一):请求头 `X-Dq-Token`、query 参数 `token`、Cookie `dq-access-token` 命中集合。
- 经 query 参数放行时,服务端 `Set-Cookie: dq-access-token=<token>; Path=/; SameSite=Strict`,后续整页跳转(如 axios 401 拦截器 `window.location.href='/activate'`)、`window.open` 下载、心跳全部靠 Cookie 自动通过。
- 前端再把 `?token=` 捕获到 sessionStorage 并给 axios/fetch 加 `X-Dq-Token` 头,作为 Cookie 失效场景的兜底。

## 改动清单

### 1. server(配置与门禁)

- `server/src/main/java/com/example/dq/config/DqProperties.java`
  - 新增 `private final List<String> accessTokens = new ArrayList<>()` + getter(注释:非空即开启浏览器访问管控)。
- `server/src/main/java/com/example/dq/config/ConfigLoader.java`
  - `load()` 中收集:yml `dq.access-token`、`System.getProperty("dq.access-token")`、env `DQ_ACCESS_TOKEN`,非空去重后加入 `dq.getAccessTokens()`。
  - 纯 Web 层管控,不进内核,`KernelConfigAdapter` 无需映射。
- `server/src/main/resources/application.yml`
  - `dq:` 下新增 `access-token: ""` 并配中文注释(配了即禁止浏览器直接访问,可用 `http://host:port/?token=xxx` 访问)。
- 新增 `server/src/main/java/com/example/dq/web/AccessGuard.java`
  - `static Handler handler(List<String> tokens)`:校验顺序 header → query → cookie;query 命中时 `ctx.header(SET_COOKIE, ...)` 种 Cookie 后放行。
  - 未命中:`/api/**` → 抛 `AccessBlockedException(json)`;GET 且末段路径不含 `.` 的(SPA 路由/首页)→ 抛 `AccessBlockedException(html 提示页)`;其余(带扩展名的静态资源)放行。
  - 内部异常类 `AccessBlockedException`(带 html/json 标记),由 WebServer 注册专属 exception mapper 写 403 响应(不能靠直接写 ctx,before 处理后 endpoint 仍会执行;也不能裸抛 Javalin `ForbiddenResponse`——会被已注册的 `Exception.class` 通用映射吃成 500)。
  - 提示文案:浏览器直接访问已被禁止,请使用桌面应用打开,或通过 `http://<host>:<port>/?token=<访问令牌>` 访问。
- `server/src/main/java/com/example/dq/web/WebServer.java`
  - 构造器读 `props.getAccessTokens()`,非空时:在 `Javalin.create` 回调里 `cfg.routes.before(...)` 注册门禁(Javalin 7 的 `RoutesConfig.before(Handler)` 已确认存在,且 before 对静态资源同样生效)、`routes.exception(AccessBlockedException.class, ...)` 注册 403 映射;启动 info 日志「浏览器访问管控已启用」(不打 token 值)。
  - 把首个 token 传给 `BrowserOpener`(见下)。
- `server/src/main/java/com/example/dq/config/BrowserOpener.java`
  - 构造器加 `String accessToken`(可空);`open(String url)` 内在 token 非空时追加 `?token=` —— jpackage 安装版配了 token 时,自动开的 --app 窗口与托盘「打开窗口」都不会把自己锁在门外。
- `server/src/main/java/com/example/dq/DqApplication.java`
  - 第二实例路径 `BrowserOpener.reopenExisting(url)`:配置了 token 时 url 追加 `?token=`(取 `config.dq().getAccessTokens()` 首个)。

### 2. web(前端 token 捕获与携带,Cookie 之外的兜底)

- 新增 `web/src/utils/access-token.js`
  - `initAccessToken()`:从 `location.search` 取 `token`,存在则写 `sessionStorage['dq-access-token']` 并用 `history.replaceState` 抹掉地址栏参数。
  - `getAccessToken()` / `appendToken(url)`(处理已有 query 的情况)。
- `web/src/main.js`:挂载前调用 `initAccessToken()`。
- `web/src/api/index.js`:axios 请求拦截器,有 token 时加 `X-Dq-Token` 头。
- `web/src/router/index.js`:`fetchLicenseStatus` 的原生 fetch 加同样头。
- `web/src/App.vue`:心跳 `axios.get('/api/heartbeat', ...)` 加同样头(裸 axios,不经过实例拦截器)。
- `web/src/components/ExportButton.vue:226`、`web/src/views/Datasources.vue:700`:`window.open` 的下载 URL 经 `appendToken()` 包装。

### 3. tauri(注入随机 token,webview 无感)

- `tauri/src-tauri/Cargo.toml`:加 `getrandom = "0.4"`(Cargo.lock 已存在 0.4.3 传递依赖,复用不增新条目;API `getrandom::fill(&mut [u8])`,编译不通过则回落 0.3/0.2 对应 API)。
- `tauri/src-tauri/src/main.rs`:
  - main 开头生成 16 字节随机数转 32 位 hex 作为 token。
  - java 命令加 `-Ddq.access-token=<token>`(开发/安装模式都加)。
  - `wait_ready`/`probe` 加 token 参数:探针请求行改为 `GET /api/license/status?token=<token> HTTP/1.0`。
  - 就绪后 navigate 到 `http://127.0.0.1:<port>/?token=<token>`;eprintln 的日志 URL 不带 token(防泄漏到日志)。

### 4. 测试

- `server/src/test/java/com/example/dq/web/WebServerSmokeTest.java` 新增用例(或单独 `WebServerAccessTokenTest`,临时数据目录):

  - 配了 token:`GET /api/datasources` 无 token → 403;带 `X-Dq-Token` 头 → 200;`GET /` 无 token → 403;`GET /?token=xxx` → 200 且响应带 `Set-Cookie`。

## 明确不做

- 不改 common 内核(纯 Web 层门禁)。
- 不引入鉴权/会话体系,token 仅作防误开门槛,与项目「无认证、内网单机」定位一致。
- 静态资源(js/css/图标)不拦,只拦页面路由与 `/api/**`。
