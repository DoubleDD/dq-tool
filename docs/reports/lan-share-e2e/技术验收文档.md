## 2. 技术方案要点

### 2.1 发现协议(UDP 广播)

- 报文:JSON(<512B),`{app:"dq-tool-lan", v:1, id, name, httpPort, appVersion}`;`v` 为协议版本,不符即忽略,演进只追加字段。
- 发送:遍历所有 up 且非回环网卡的广播地址群发;监听与发送同端口,`SO_REUSEADDR` 支持同机多实例。
- 在线表:纯内存,按 instanceId 去重;peer 的 IP 取报文来源地址(不信自报);3 个心跳间隔未见即剔除。
- 实例身份:instanceId 首启生成并持久化(`system_settings.instance_id`);实例名可页面修改,下个心跳生效。

### 2.2 数据通道(HTTP 点对点)

- 共享出口(对方拉取用,授权前置校验放行,就绪闸门仍生效):
  - `GET /api/lan/share/annotations/preview` — 标注预览(含逐行明细):标记定义清单 + 按数据源分布计数 + 打标/描述/所属系统逐行;
  - `GET /api/lan/share/annotations` — 全部标记定义+表级打标+表描述+表所属系统(与手工导出同格式);
  - `GET /api/lan/share/scans/preview` — 扫描任务摘要列表(供勾选);
  - `GET /api/lan/share/scans?ids=` — 扫描记录导出(与手工导出同格式;ids 逗号分隔,空=全部);
  - `GET /api/lan/share/datasources` — 数据源清单(名称/jdbcUrl/用户名/库过滤/分组 + TransferCrypto 密文的密码与 SSH 秘密字段,与数据源导出文件同一口径,无明文)。
- 管理端点(本机页面用,正常授权校验):`GET /api/lan/status`、`GET /api/lan/peers`、`PUT /api/lan/settings`、
  `GET /api/lan/preview/{instanceId}`(聚合对方预览 + 数据源映射预匹配,同步前弹窗数据源)、
  `POST /api/lan/pull/{instanceId}`(按勾选拉取:标注选择 + 扫描任务 id 列表 + dsMapping + createDatasources)。
- 数据源映射:用户确认的 dsMapping(对方名 → 本机 id,0=跳过)优先;createDatasources 里的对方数据源
  先建成副本(名称/jdbcUrl/用户名/库过滤/分组,密码与 SSH 秘密字段经 TransferCrypto 密文传输后解密落库,
  与数据源导出文件同一口径)再映射到新 id;
  同名已存在则直接用现有的不建重名副本;扫描记录对未映射的名按名回退自动匹配。
- 拉取合并完全复用现有 Transfer 导入路径:标记按名合并;表级数据按 数据源名+db+schema+table 对齐(经映射);
  标注按用户勾选在本机侧过滤后再导入(标记定义只留勾选的,表级打标只带勾选标记的关系);
  单段失败不中断另一段。

### 2.3 兼容与幂等

- 数据格式与手工导出/导入文件同源,遵守「同版本追加可选字段、导入忽略未知字段」铁律——新旧版本实例互相拉取不产生静默错误。
- 扫描任务按 数据源+db+schema+created_at 去重;表标记/描述/所属系统均 MERGE 幂等。重复拉取、多人交叉拉取均安全。

### 2.4 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `dq.lan.enabled` | true | 总开关;页面开关落 `system_settings.lan_enabled` 覆盖并即时启停 |
| `dq.lan.discovery-port` | 17386 | UDP 发现端口,同网段各实例需一致 |
| `dq.lan.announce-interval-seconds` | 5 | 心跳间隔;离线判定 = 3 倍间隔 |

库表变更:仅 `V33__lan_share.sql`(system_settings 加 3 列,ALTER IF NOT EXISTS,新老库路径收敛)。

## 3. 安全边界

- 共享出口**无鉴权**,与工具整体「无登录、仅内网单机/可信网络」定位一致;开启共享后同网段任何人可拉取本机标记/描述/扫描记录与数据源清单。
- 数据源清单中的密码与 SSH 秘密字段为 **TransferCrypto 密文**(AES-GCM + 固定内置口令,与数据源导出文件同一口径,跨实例可解、无明文);内置口令是「防随手打开」级别保护,并非强安全设计——不可信网络不要开启共享。
- 页面可一键关闭共享(即时停止发现与广播);不需要该功能的部署置 `dq.lan.enabled=false` 即可完全关闭。
- 心跳报文不含任何业务数据,仅实例身份与端口。

## 4. 已知限制

- UDP 广播跨不出 VLAN/路由器;无线 AP 开了客户端隔离时互相收不到心跳。此时在线列表为空,不影响其他功能,可回退手工导出/导入文件方式。
- 同步为手动拉模式,无实时自动同步;数据源名不一致时由用户在预览弹窗做映射(或新建副本),未映射且未新建的数据源其数据跳过并记 warning。
- 资源占用:每实例每 5s 一个 <512B 广播包 + 内存在线表,可忽略。
