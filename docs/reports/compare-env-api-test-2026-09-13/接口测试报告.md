## 关键发现

### BUG(阻断级,已修复):`GET /api/compare-jobs/{id}/diffs` 恒 500

- **位置**:`server/src/main/java/com/example/dq/controller/CompareController.java` 第 41 行

  ```java
  Long targetId = ctx.queryParamAsClass("targetId", Long.class).getOrDefault(null);
  ```

- **根因**:Javalin 7.2.2 的 `Validator.getOrDefault(T default)` 是 Kotlin 方法,形参 `default` 为**非空**。
  Java 侧传 `null` 时,`Intrinsics.checkNotNullParameter` 在方法体执行前就抛异常——所以**即使请求带了 `targetId` 也照样 500**,与参数是否缺失无关。
- **影响面**:前端 `CompareDiff.vue` 对每个 DONE target 循环调用该接口拉全量差异明细,因此
  **「数据比对 → 差异明细」页签完全不可用**;任务列表、任务详情、质量报告、差异导出均不受影响。
- **建议修复**(Javalin 7.2.2 已提供 `getOrNull()`,一行):

  ```java
  Long targetId = ctx.queryParamAsClass("targetId", Long.class).getOrNull();
  ```

- **单测空白(已补)**:`common/src/test/kotlin/com/example/dq/service/CompareDiffTest.kt` 只覆盖纯函数
  `CompareService.diffObjects`,控制器查询参数解析原先无任何测试,故未被发现。

### 修复与复测(2026-09-13)

- **修复**:`CompareController.java` 第 41 行改为 `getOrNull()`(Javalin 7.2.2 的 `Validator` 提供)
- **回归测试**:`WebServerSmokeTest` 新增 `比对差异明细分页缺省targetId不报Kotlin非空NPE()`,
  以「任务不存在时应由业务层返回 400,而不是停在参数解析的 500」断言,覆盖 4 种参数组合;
  因 `/api/compare-jobs/**` 受受控功能 `compare` 约束,同步新增 `activateLicense("compare")` 重载
- **验证**:`./gradlew :server:test --tests com.example.dq.web.WebServerSmokeTest` — 25 个用例全绿
- **复测(重启实例后)**:

  | 请求 | 修复前 | 修复后 |
